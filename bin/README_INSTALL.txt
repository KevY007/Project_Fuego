<!> Welcome to Project Fuego <!>
In this package, there are several files that this README will tell you about.
1) d3d9.dll - This is the main heart of the s0biet, it contains the hooking, hacks and all stuff.
2) AntTweakBar.dll - This is one of the main things to get the s0biet working, This is the sexy bars you see in the menu.
3) fuego_font.ttf - This is not really needed since this is a font file but it can allow you to use chat in other font (f7)

4) ---------- Contents of project_fuego folder-----------
 * friends.txt - This contains the names of your friends etc, they will be avoided by Silent Aimbot.
 * fuego.ini - Contains the configuration for keys, etc and the s0biet, MUST be present.
 *  .png and .raw files - Don't remove these, these are required for speedometer etc.
 * wordlist.txt - Contains wordlist for auto unscrambler LSRP, after it has been modified /autouns_reload in the game to reload the list.

5) fuego_noactivations.ini - READ THOROUGHLY NOW!
 --------------------------------------------------
This INI configuration files is a modified version of the default fuego.ini inside the project_fuego folder.
This INI configuration has disabled all keys to hacks like airbreak, weapon hack, money hack, fly etc. So you can safely
use the mod in any other server like for playing LSRP regularly and not activating a hack by mistake.
This will also enable the built-in anti mistake feature where all big hacks like Slappers, Killers, Car shooters, Car hacks
Car exploder won't be enabled no matter how many times you click on their box to enable it, to disable this ingame, you can
use the command /toggle_big_hacks to toggle between OFF and ON mode to toggle anti big hacks feature. This is not enabled by
default in the normal activation ini.

WHEN USING THIS CONFIGURATION DO NOT PRESS F15 IF YOUR KEYBOARD HAS.
ALL THE KEYS FOR HACKS SUCH AS WARPING HAVE BEEN MOVED TO F15 TO AVOID MISS CLICKS!

To install this: Simply backup or rename the current fuego.ini in project_fuego folder, and then copy this .ini and then rename
the fuego_noactivations.ini to fuego.ini

IN simple terms:
1) project_fuego/fuego.ini -> (RENAME/MOVE/DELETE) -> project_fuego/fuego_backup.ini
2) fuego_noactivations.ini -> MOVE TO-> project_fuego/fuego_noactivations.ini
3) project_fuego/fuego_noactivations.ini -> (RENAME) -> project_fuego/fuego.ini

________________________________________________________________________________________________________________________
					HOW TO INSTALL
________________________________________________________________________________________________________________________
Install font file (OPTIONAL)
Move all files (d3d9, AntTweakBar, project_fuego folder, and optionally the fuego_noactivations.ini) to GTA SA ROOT folder.
Go ingame and press F2 to toggle the AntTweakBar / Hack menu.

_________________________________
To Uninstall:
_________________________________
Delete all files you've moved into folder including d3d9, AntTweakBar, project_fuego etc and they will get removed.


Crashing? Maybe try this:
1) GET RID OF OPENLIMITADJUSTER, THIS CONFLICTS VERY BADLY.
2) Get rid of ENB files etc.
3) Get rid of .ASI mods that you don't really need like SilentPatch (doesn't cause problems tho)
